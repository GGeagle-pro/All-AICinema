토큰 만드는 방법은 설치 가이드의 "관리자 페이지 설정"을 보세요.

유튜브 채널 추가

유튜브 앱·사이트에서 채널 주소를 복사해 붙여넣고, 카테고리를 고른 뒤 추가하면 1~3분 안에 사이트에 올라가요. 영상 주소를 넣으면 그 영상 하나만 추가돼요.

카테고리 (여러 개 선택 가능)

등록된 채널

    작품별 묶기

    영상은 수집할 때 채널이 만든 유튜브 재생목록과 제목을 보고 작품별로 자동으로 묶여요. 잘못 묶였으면 여기서 이름을 바꾸거나, 다른 작품과 합치거나, 묶지 않게 할 수 있어요. 자동으로 안 묶인 영상은 "규칙 추가"로 제목 단어를 지정하면 돼요. 저장하면 1~3분 뒤 사이트에 반영돼요.

      여기 있는 영상은 채널에 새로 올라와도 사이트에 다시 나타나지 않아요. 복원하면 다음 수집 때 다시 보여요.

        카테고리 (사이트 1줄 메뉴)

        AI 드라마, AI 영화, 한국, 중국, 일본처럼 사이트 위쪽 첫 줄에 보일 카테고리예요. 여기서 순서를 바꾸거나 지울 수 있고, "채널 관리"의 채널 추가 화면에서도 바로 만들 수 있어요. 각 채널이 어떤 카테고리에 나올지는 "채널 관리"에서 정해요. 2줄 메뉴(유튜브 채널 이름)는 자동으로 만들어져요.

          광고 배너 3칸

          사이트의 "지금 보기" 영역과 "최신 영상" 사이에 보이는 배너예요. 이미지를 올리고 클릭하면 이동할 주소를 넣으세요. 권장 크기는 가로 1200 × 세로 525 (16:7)이고, 사이트에는 "광고" 표시가 함께 나와요.

          애드센스 광고 번호

          애드센스 → 광고 → 광고 단위 기준 → 디스플레이 광고에서 광고를 만들고, 코드 안의 data-ad-slot="숫자" 숫자를 넣으세요. 비워둔 자리는 광고가 나오지 않아요.

          영상 여는 방식

          애드센스 전면 광고(비네트)는 구글이 사이트 안에서 페이지를 이동할 때만 보여줘요. "페이지 이동"으로 두면 목록에서 영상을 누를 때 영상 페이지로 실제 이동해서 전면 광고가 나올 기회가 생겨요. 언제든 "바로 재생"으로 되돌릴 수 있어요.

          상·하단 고정 광고와 전면 광고 켜기

          화면에 계속 붙어 있는 상단·하단 고정 광고와 페이지를 이동할 때 나오는 전면 광고는 애드센스 정책상 직접 코드로 넣을 수 없고, 구글의 "자동 광고"로 켜야 해요. 사이트에는 이미 준비되어 있어서 애드센스 화면에서 켜기만 하면 돼요.

          1. 애드센스 → 광고 → 사이트 기준 → 사이트 옆 수정(연필)
          2. 오른쪽에서 자동 광고를 켜요.
          3. 오버레이 형식에서 앵커 광고(상단 또는 하단 고정)와 비네트 광고(전면 광고)를 켜요. 원하면 사이드 레일 광고도 켤 수 있어요.
          4. 사이트에 적용을 눌러요. 반영까지 최대 1시간 걸려요.

          양옆 세로 광고(160×600)는 PC 화면에서 양쪽 똑같이 페이지와 함께 움직여요. 번호를 한쪽에만 넣어도 양쪽에 같은 광고 단위가 쓰여요. (애드센스 정책상 양쪽 모두 따라오게 할 수는 없어요.)
