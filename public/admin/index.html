    관리자 로그인

    GitHub 저장소 이름과 토큰을 넣으세요. 토큰은 이 브라우저에만 저장되고, GitHub 외에는 어디에도 보내지 않아요.

    토큰 만드는 방법은 설치 가이드의 "관리자 페이지 설정"을 보세요. 보안을 위해 Fine-grained 토큰, 저장소는 이 저장소 하나만, 만료는 90일 이하로 만들어 주세요. 공용 PC에서는 "로그인 유지"를 켜지 마세요.

    관리자를 앱처럼 쓰기홈 화면 아이콘으로 바로 열리고, 주소창 없이 앱처럼 보여요.

    한눈에 보기

    방문자·재생 오류·채널 성과는 통계 암호를 한 번 넣으면 보여요.

    재생 오류 (최근 7일 · 사이트 플레이어에서 재생이 안 된 영상)

    101·150 = 제작자가 다른 사이트 재생을 막음, 100 = 삭제·비공개, 5 = 브라우저 재생 오류, 2 = 잘못된 영상 번호. 같은 영상이 자주 나오면 숨기기를 눌러 주세요.

      채널별 성과 (최근 30일)

      사이트 재생 = 사이트에서 그 채널 영상을 연 횟수(GA). 유튜브 조회수 = 사이트에 있는 그 채널 영상들의 유튜브 전체 조회수 합. 제목을 누르면 정렬 기준이 바뀌어요.

      보안 점검

      펼쳐 보기
      • GitHub 토큰 만료 90일 이하 – GitHub → Settings → Developer settings → Fine-grained tokens 에서 이 토큰의 Expires 날짜를 확인하세요. 만료가 없거나 90일보다 길면 새로 만들어(90일) 바꿔 넣어 주세요.
      • 애드센스 OAuth 클라이언트 보안 비밀 – 예전에 캡처로 보였던 값은 바꾸는 걸 권장해요. Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 → 보안 비밀 추가 → 새 값을 GitHub Secrets 의 ADSENSE_CLIENT_SECRET 에 넣고, 통계 '지금 새로 가져오기'가 되는지 확인한 뒤 옛 보안 비밀을 사용 중지·삭제. 보안 비밀 목록에 생성일이 하나뿐이고 그날이 처음 만든 날이면 아직 안 바꾼 거예요.
      • 저장소 비공개 전환 – 원하실 때 하면 돼요. 순서(Cloudways 배포 키 등록 → 비공개 전환 → 확인)는 프로젝트 문서 "작업 원칙"에 저장돼 있어요. 비공개면 GitHub Actions 무료 사용량이 월 2,000분으로 줄어요.
      • 받은 JSON 키 파일 – 서비스 계정 키(.json)를 내려받은 PC에 남아 있으면 지워 주세요. 값은 GitHub Secrets 에만 있으면 돼요.

      유튜브 앱·사이트에서 채널 주소를 복사해 붙여넣고, 카테고리를 고른 뒤 추가하면 1~3분 안에 사이트에 올라가요. 영상 주소를 넣으면 그 영상 하나만 추가돼요.

      카테고리 (여러 개 선택 가능)

      등록된 채널

        뺀 채널 (자동·게임 등)

        영상 대부분을 다른 사이트에서 재생할 수 없게 막아 둔 채널은 매일 확인해서 자동 수집에서 빼요(영상 3개 이상 중 80% 이상 막힘, 영상이 1~2개면 전부 막힘). 막힌 영상은 채널과 상관없이 사이트에서 빠져요. 되살리기를 누르면 다시 수집하고, 그 뒤로는 자동으로 빼지 않아요(막힌 영상만 계속 제외).

          작품별 묶기

          영상은 수집할 때 채널이 만든 유튜브 재생목록과 제목을 보고 작품별로 자동으로 묶여요. 잘못 묶였으면 여기서 이름을 바꾸거나, 다른 작품과 합치거나, 묶지 않게 할 수 있어요. 자동으로 안 묶인 영상은 "규칙 추가"로 제목 단어를 지정하면 돼요. 저장하면 1~3분 뒤 사이트에 반영돼요.

          검색용 작품·영상 페이지

          구글 검색에 작품·영상이 하나하나 나오도록 /work/작품이름/, /watch/영상ID/ 페이지를 자동으로 만들어요. 끄면 3~5분 뒤 이 페이지들이 모두 지워지고 사이트맵·링크도 예전으로 돌아가요(원상 복구). 다시 켜면 그대로 다시 만들어져요.

            여기 있는 영상은 채널에 새로 올라와도 사이트에 다시 나타나지 않아요. 복원하면 다음 수집 때 다시 보여요.

              카테고리 (사이트 1줄 메뉴)

              AI 드라마, AI 영화, 한국, 중국, 일본처럼 사이트 위쪽 첫 줄에 보일 카테고리예요. 여기서 순서를 바꾸거나 지울 수 있고, "채널 관리"의 채널 추가 화면에서도 바로 만들 수 있어요. 각 채널이 어떤 카테고리에 나올지는 "채널 관리"에서 정해요. 2줄 메뉴(유튜브 채널 이름)는 자동으로 만들어져요.

                영상 언어로 국가 정하기

                지금은 영상의 국가가 채널에 지정한 국가를 따라가요. 켜면 영상 제목의 언어를 보고 국가를 정해요(한국어→한국, 일본어→일본, 중국어→중국, 스페인어→스페인, 프랑스어→프랑스, 인도네시아어→인도네시아, 영어→미국). 언어를 알 수 없거나 그 국가가 메뉴에 없으면 채널 국가 그대로예요. 장르는 바뀌지 않아요. 끄면 원래대로 돌아가요(원상 복구). 저장 후 3~5분 뒤 사이트에 반영돼요.

                  광고 칸별 성과

                  노출 = 배너가 화면에 절반 이상 1초 넘게 보인 횟수, 클릭률 = 클릭 ÷ 노출. 칸별 기록은 2026-11-23 밤부터 쌓이고, 구글 통계 특성상 몇 시간~하루 늦게 반영돼요(통계는 2시간마다 가져와요).

                  광고 배너 3칸

                  사이트의 "지금 보기" 영역과 "최신 영상" 사이에 보이는 배너예요. 칸마다 모든 방문자 / 국내(한국) 방문자만 / 해외 방문자만 중 누구에게 보일지 고를 수 있어요(접속 IP 국가 기준). 이미지를 올리고 클릭하면 이동할 주소를 넣으세요. 권장 크기는 가로 1200 × 세로 525 (16:7)이고, 사이트에는 "광고" 표시가 함께 나와요. 칸마다 아래 "예약 광고"를 펼치면 광고주 배너를 시작·끝 날짜와 시간으로 예약할 수 있어요. 그 기간에만 예약 광고가 보이고, 끝나면 위에 저장한 기본 광고로 자동으로 돌아가요(다음 광고도 미리 여러 개 예약 가능).

                  목록 사이 띠 배너

                  메인의 줄과 줄 사이(2번째 줄 다음, 그 뒤 5줄마다)와 영상 목록 중간(애드센스 광고 사이 가운데: 18·54·90번째 뒤)에 보이는 가로로 긴 배너예요. 이미지를 올리고 클릭하면 이동할 주소를 넣으세요. 권장 크기는 가로 1920 × 세로 240 (8:1)이에요. PC에서는 목록 폭에 꽉 차게 전체가 보이고, 모바일에서는 양옆이 잘려 가운데 1440px만 보이니 글자·로고는 가운데에 넣어 주세요. 최대 6개까지 넣을 수 있고, 칸마다 국내 방문자 / 해외 방문자 / 모두 중 누구에게 보일지 고를 수 있어요(예: 국내는 쿠팡, 해외는 AI 도구 제휴). 쿠팡파트너스처럼 수수료 고지가 필요한 배너는 "제휴 고지 문구"를 꼭 넣어 주세요. 여러 개를 채우면 돌아가며 보이고, 여러 개를 채우면 돌아가며 보여요. 사이트에는 "광고" 표시가 함께 나와요. 칸마다 아래 "예약 광고"를 펼치면 광고주 배너를 시작·끝 날짜와 시간으로 예약할 수 있어요. 그 기간에만 예약 광고가 보이고, 끝나면 위에 저장한 기본 광고로 자동으로 돌아가요(다음 광고도 미리 여러 개 예약 가능).

                  AI 제작 도구 추천 페이지 페이지 보기 ↗

                  사이트 하단 "AI 제작 도구" 링크로 들어가는 추천 페이지예요(한국어·영어·일본어·중국어·스페인어 5개 언어, 검색 노출용). 도구마다 제휴 링크를 넣으면 공식 사이트 대신 그 링크로 연결되고, 페이지 위에 제휴 고지 문구가 자동으로 붙어요. 비우면 공식 사이트로 연결돼요. 저장 후 3~5분 뒤 반영돼요.

                  애드센스 광고 번호

                  애드센스 → 광고 → 광고 단위 기준 → 디스플레이 광고에서 광고를 만들고, 코드 안의 data-ad-slot="숫자" 숫자를 넣으세요. 비워둔 자리는 광고가 나오지 않아요.

                  영상 여는 방식

                  애드센스 전면 광고(비네트)는 구글이 사이트 안에서 페이지를 이동할 때만 보여줘요. "페이지 이동"으로 두면 목록에서 영상을 누를 때 영상 페이지로 실제 이동해서 전면 광고가 나올 기회가 생겨요. 언제든 "바로 재생"으로 되돌릴 수 있어요.

                  상·하단 고정 광고와 전면 광고 켜기

                  화면에 계속 붙어 있는 상단·하단 고정 광고와 페이지를 이동할 때 나오는 전면 광고는 애드센스 정책상 직접 코드로 넣을 수 없고, 구글의 "자동 광고"로 켜야 해요. 사이트에는 이미 준비되어 있어서 애드센스 화면에서 켜기만 하면 돼요.

                  1. 애드센스 → 광고 → 사이트 기준 → 사이트 옆 수정(연필)
                  2. 오른쪽에서 자동 광고를 켜요.
                  3. 오버레이 형식에서 앵커 광고(상단 또는 하단 고정)와 비네트 광고(전면 광고)를 켜요. 원하면 사이드 레일 광고도 켤 수 있어요.
                  4. 사이트에 적용을 눌러요. 반영까지 최대 1시간 걸려요.

                  양옆 세로 광고(160×600)는 PC 화면에서 양쪽 똑같이 페이지와 함께 움직여요. 번호를 한쪽에만 넣어도 양쪽에 같은 광고 단위가 쓰여요. (애드센스 정책상 양쪽 모두 따라오게 할 수는 없어요.)

                  카카오톡 공유 (선택)

                  영상 화면의 공유 → 카카오톡을 누르면 바로 카카오톡 친구·채팅방 고르기 창이 뜨게 하려면 카카오 JavaScript 키를 넣어 주세요. 비워 두면 휴대폰은 기기 공유 창(카카오톡 선택), PC는 링크 복사로 동작해요. 키 받는 곳: developers.kakao.com → 앱 만들기 → 앱 → 플랫폼 키 → JavaScript 키 복사, 같은 곳 JavaScript SDK 도메인에 https://all-aicinema.syncbrain100.com 등록, 그리고 앱 → 제품 링크 관리 → 웹 도메인에도 같은 주소를 꼭 등록(빠지면 공유할 때 4002 오류). 이 키는 공개용이라 사이트에 넣어도 괜찮아요.
